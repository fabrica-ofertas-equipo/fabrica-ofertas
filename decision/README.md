# decision
Lógica determinista de decisión entre etapas: puertas de calidad, estados de oferta, sellos por hash de QA.
Propietario: O0 y las etapas D3-D4 (validación y oferta); consume engine/.
Los LLM proponen, el código dispone: aquí vive el 'dispone'.
CLI: python -m decision.<modulo> [--live].
Probar: python3 -m unittest discover -s tests/decision -t .
